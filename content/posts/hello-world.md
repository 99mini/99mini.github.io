# Hello, World!

새로운 블로그에 오신 것을 환영합니다.

이 블로그는 다음 기술로 만들어졌습니다:

- **React 19** + **TanStack Router** — 파일 기반 라우팅과 SSG
- **TypeScript 6** — 강력한 타입 안전성
- **TailwindCSS v4** — CSS-first 스타일링
- **Motion v12** — 부드러운 애니메이션
- **Biome** — 빠른 린팅과 포매팅

## 코드 예시

```typescript
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/")({
  component: () => <h1>Hello, World!</h1>,
});
```

앞으로 개발 경험과 기술 글을 공유할 예정입니다. 🚀
