# 005 SEO 전략

## 개요

크롤러(검색 엔진, SNS 미리보기)와 브라우저 내비게이션 양쪽을 모두 지원하는 두 레이어 SEO 전략을 사용합니다. 빌드 타임 정적 주입과 클라이언트 사이드 동적 업데이트를 함께 사용합니다.

## 배경 / 동기

- 정적 배포 환경에서는 각 URL의 HTML 파일에 메타 태그가 있어야 크롤러가 읽을 수 있음
- SPA 내비게이션 중에는 HTML 파일이 교체되지 않으므로 JS로 메타 태그를 동적으로 업데이트해야 함
- 두 레이어가 없으면 크롤러에게는 모든 페이지가 동일한 메타데이터로 보임

## 설계 결정

### 두 레이어 역할 분리

| 레이어 | 담당 | 대상 |
|--------|------|------|
| `scripts/prerender.ts` | 빌드 타임 정적 주입 | 크롤러, SNS 봇, 초기 HTML |
| `<SEO>` 컴포넌트 | 런타임 동적 업데이트 | SPA 내비게이션 후 브라우저 탭 |

## 구조

```
빌드 타임:
  scripts/prerender.ts
    └── dist/{route}/index.html
          ├── <title>페이지 제목</title>
          ├── <meta property="og:title" content="...">
          ├── <meta property="og:description" content="...">
          ├── <meta property="og:url" content="...">
          ├── <meta property="og:image" content="...">
          ├── <meta property="og:type" content="...">
          ├── <meta name="twitter:card" content="...">
          ├── <meta name="twitter:title" content="...">
          └── <meta name="twitter:description" content="...">

런타임:
  src/components/SEO.tsx
    └── useEffect (마운트 + 라우트 변경 시)
          ├── document.title 업데이트
          └── <meta> 태그 content 업데이트
```

## 주요 파일

| 파일 | 역할 |
|------|------|
| `src/components/SEO.tsx` | 런타임 메타 태그 업데이트 컴포넌트 |
| `scripts/prerender.ts` | 빌드 타임 HTML 메타 태그 주입 |

## 사용 방법

### 라우트에서 SEO 컴포넌트 사용

```typescript
// src/routes/about.tsx
import { SEO } from "@/components/SEO";

function AboutPage() {
  return (
    <>
      <SEO
        title="소개 | 99mini"
        description="개발자 99mini의 소개 페이지"
        url="https://99mini.github.io/about"
      />
      <main>...</main>
    </>
  );
}
```

### 블로그 포스트에서 동적 SEO

```typescript
// src/routes/post/$slug.tsx
function PostPage() {
  const post = Route.useLoaderData();
  return (
    <>
      <SEO
        title={`${post.title} | 99mini`}
        description={post.summary}
        url={`https://99mini.github.io/post/${post.slug}`}
        image={post.thumbnail}
        type="article"
      />
      <article>...</article>
    </>
  );
}
```

### prerender.ts에 라우트 메타 추가

```typescript
// scripts/prerender.ts
const routes = [
  {
    path: "/new-page",
    title: "새 페이지 | 99mini",
    description: "새 페이지 설명",
    ogImage: "https://99mini.github.io/og-image.png",
  },
];
```

## 주입되는 메타 태그 목록

```html
<title>{title}</title>
<meta name="description" content="{description}">
<meta property="og:title" content="{title}">
<meta property="og:description" content="{description}">
<meta property="og:url" content="{url}">
<meta property="og:image" content="{image}">
<meta property="og:type" content="website | article">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="{title}">
<meta name="twitter:description" content="{description}">
```

## 주의 사항

- 빌드 타임과 런타임의 메타 태그 내용이 일치해야 함 — 불일치 시 크롤러와 사용자가 다른 정보를 봄
- `<SEO>` 컴포넌트는 기존 `<meta>` 태그를 업데이트하는 방식으로 동작하므로, `index.html`에 placeholder 태그가 있어야 함
- 새 정적 라우트 추가 시 반드시 `prerender.ts`에도 추가해야 크롤러가 올바른 메타데이터를 받음
